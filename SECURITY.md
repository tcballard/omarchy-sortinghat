# Security policy

Do not attach sensitive filenames, complete paths or file contents to a public report. Describe the coarse failure and use synthetic fixtures. Report privately to the repository owner when disclosure could expose a user's filesystem or permit unintended mutation.

SortingHat never offers delete or overwrite. A verified cross-filesystem move removes the exact source inode only after durable destination publication and checksum verification. If recovery evidence is ambiguous, it preserves copies and requires attention.
